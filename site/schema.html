Schema docs

This page is rendered client-side from the JSON Schema files in schema/v0.1/, so it always matches the format the validator enforces. Conventions: snake_case keys; SI units are named in the key (_m metres, _kg kilograms, _ms metres per second, _ha hectares, _c °C, _s seconds, _hz hertz, _y years); fractions are 0..1; months are 1..12; dates are YYYY-MM-DD; month-day windows are MM-DD. Unknown keys are rejected everywhere except inside extensions. A $ref in a type column links to that type's own section below.
