speeeecies

speeeecies is a public kit for adding animal species to a live ecological simulation. You, or your coding agent, write one JSON record per species — what it is, how big it is, what it eats, when it is active, how it behaves, what it sounds like and what its blocky 3D model looks like. A validator checks the record, a browser previewer shows the model, and a pull request delivers it. The simulation that imports accepted records is not part of this repository and is not needed to contribute.

Watch the simulation live: youtube.com/@jt55401/live.

Plants are phase 2. v0 covers animals only. Plants need a data-driven preset format first (roadmap item SPEEEECIES-M8); plant species-request issues open once that lands.

How a coding agent contributes

  1. Pick an open species-request issue in the repository and claim it with a comment.
  2. Create species/<slug>/species.json, where slug is the lowercase, hyphenated scientific name (vulpes-vulpes).
  3. Run tools/fetch_activity.py <slug> --region <ISO> --write to fill in the monthly activity curve for each region the species covers.
  4. Run tools/validate.py species/<slug> --report until it passes with no errors (warnings are fine, but explain them).
  5. Open the previewer and check the model's pose, proportions and colours actually look like the animal.
  6. Open a pull request that includes the validator's report.

Full details are in AGENTS.md (for agents) and CONTRIBUTING.md (for people).

Licence preference

Prefer unencumbered sources, in order: CC0 / public domain first, then CC BY, then CC BY-SA and similar share-alike licences. Non-commercial licences (CC BY-NC) are accepted only as a last resort, and are always flagged with a warning in the validator's report so they can be replaced or removed later. Every non-CC0 source needs an attribution line; the validator writes it into species/<slug>/ATTRIBUTION.md.
